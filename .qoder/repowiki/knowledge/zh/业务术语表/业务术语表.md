### JSAPI 支付
- 定义：微信支付 JSAPI 产品，指微信公众号网页或小程序内调起支付的场景，对应 APIv3 端点 POST /v3/pay/transactions/jsapi，trade_type=JSAPI，必须传入 payer.openid；本项目当前唯一目标对接模式。
- 别名：JSAPI、微信内 H5、jsapi.JsapiApiService

### H5 支付
- 定义：微信支付产品线中的「H5 支付」（MWEB），指微信外手机浏览器（Safari/Chrome/UC）下单后 302 跳转唤起微信，对应端点 POST /v3/pay/transactions/h5，trade_type=MWEB，返回 h5_url，不需要 openid；本项目声明了 TradeTypeH5 但尚未实现，PrepayResult 也缺少 h5_url 字段。
- 别名：MWEB、微信外 H5、TradeTypeH5

### NATIVE 支付
- 定义：微信支付 NATIVE 扫码支付，trade_type=NATIVE，渠道返回 code_url（如 weixin://wxpay/bizpayurl?…），由前端渲染二维码；本项目 mock 已返回 CodeURL，但真实接入方案尚未编写。
- 别名：Native、TradeTypeNATIVE、扫码支付

### APP 支付
- 定义：微信支付 APP 原生支付，trade_type=APP，返回 partnerid/prepayid/sign 等下划线命名字段供原生 SDK 调用；本项目仅声明常量，mock 走 default 分支返回错误的 InvokeParams 结构。
- 别名：TradeTypeAPP、AppPay

### Gateway 接口
- 定义：channel.Gateway 是本项目支付渠道抽象层的核心接口，定义 Code/Prepay/QueryOrder/CloseOrder/ParseNotify/Refund 六个方法，将 service 层与具体支付厂商解耦；新增渠道只需实现该接口并在 app.buildRegistry 中按配置注册。
- 别名：channel.Gateway、渠道抽象层、Gateway

### Mock 渠道
- 定义：internal/channel/mock 提供的内存仿真支付渠道，用于本地端到端跑通「下单→预支付→回调→查单」全流程，不产生真实扣款；仅在 server.mode=debug 下注册，release 模式下禁用以避免资金漏洞。
- 别名：mock、仿真渠道、mock_gateway

### 回调验签
- 定义：处理微信支付异步通知时必须完成的步骤：读取 Wechatpay-Signature/Wechatpay-Timestamp/Wechatpay-Nonce/Wechatpay-Serial 四个请求头，用 APIv3 密钥做 AES-256-GCM 解密并校验签名；校验失败应拒绝报文而不交给业务层。
- 别名：ParseNotify 验签、支付结果通知验签、RSA NotifyHandler

### 证书模式 / 公钥模式
- 定义：微信支付 APIv3 的两种验签/加密凭据形态：证书模式使用商户 API 证书与平台证书，公钥模式使用微信支付平台公钥；config.WechatPayConfig 两套字段均预留，Validate() 要求至少配齐一套才能启用 wechatpay 渠道。
- 别名：验签模式、证书模式、公钥模式

### 运行模式
- 定义：server.mode 的 debug/release/test 三种运行态：debug 注册 mock 路由与 mock trigger；release 禁用 mock 路由且强制 require HTTPS 回调地址；test 用于测试环境。release 下若微信支付未启用则启动直接失败。
- 别名：server.mode、debug 模式、release 模式

### 订单状态机
- 定义：领域模型中 Order 的状态流转：CREATED → PAYING → PAID，PAYING 可转 CLOSED/REFUNDED；Payment 流水：INIT → PREPAID → SUCCESS，PREPAID 可转 FAILED/CLOSED。非法流转由 model.transit() 直接报错，service 层不判断状态字符串。
- 别名：Order 状态机、Payment 状态机、transit

### 金额分位存储
- 定义：项目内金额一律以 int64「分」存储，对外暴露 string「元」；money 包基于 math/big 做元分转换，禁止 float64 参与计算，防止精度丢失导致资金事故。
- 别名：分、amount_fen、金额单位

### draft-copy-then-swap
- 定义：内存仓储的并发写策略：读锁内拷贝 map 副本，修改副本后用写锁 swap 回原位置；对外返回 Clone() 快照，调用方修改不影响仓储内部数据。换 MySQL 只需新增 repository 实现。
- 别名：草稿复制替换、RWMutex + map
