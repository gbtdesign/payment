- 金额在系统内一律以 int64「分」表示，所有元分转换与比较都通过 money 包的函数完成，禁止直接使用 float64 或裸算术运算。
- 对外返回的错误统一包装为 errcode.Error，并通过 response.Fail/Abort 映射为 {code,message,data,request_id} 的 JSON 响应，HTTP 状态码与业务码同时给出。
- 随机数与 ID 生成使用 crypto/rand 而非 math/rand，并在熵源异常时退化到时间派生，保证 ID 生成不会成为可用性瓶颈。
- 全局可变状态（如 logger.base）通过 sync/atomic.Pointer 读写，避免 -race 检测到的数据竞争。
- 错误码按千位段划分领域（10xxx/20xxx/30xxx/40xxx），每个错误码固定绑定一个 http.Status，新增错误需保持该约定。
