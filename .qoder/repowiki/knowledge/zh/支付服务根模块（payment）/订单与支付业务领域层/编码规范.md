- 领域实体的状态变更统一通过 Mark* 方法进入 transit 校验，禁止外部直接赋值 Status 字段。
- HTTP 层的请求/响应结构体与领域模型分离，转换逻辑集中在 dto 包的 From* 函数中。
- 金额在 API 边界以字符串「元」传输，领域与服务层统一使用 int64「分」，避免浮点精度问题。
- 服务构造采用 NewXxx 函数 + 依赖注入（repository、channel.Registry、配置前缀），不使用全局变量。
- 对外返回的错误统一经 errcode 包装（WithCause / WithMsg），仓储层已带错误码的错误直接透传。
- 时间戳在 DTO 输出时统一格式化为 RFC3339，零值时间省略字段以避免客户端误读。
